DoğaYol, doğa ve seyahat temalı, HTML ve CSS kullanılarak geliştirilmiş responsive bir web sitesi tasarım projesidir.
Bu proje, HTML ve CSS öğrenme sürecimde geliştirdiğim ilk uygulamalı web sitesi çalışmasıdır. Amacım, bir referans tasarımı kendi kodlarımla oluşturarak temel web geliştirme becerilerimi pekiştirmekti.

Kullanılan Teknolojiler:

-HTML5
-CSS3
-Flexbox
-CSS Grid
-Media Queries

Proje Özellikleri:

Responsive navigasyon tasarımı
Görsel arka planlı Hero bölümü
Hakkımızda ve Hizmetlerimiz bölümleri
Popüler Rotalar kartları
Hover efektleri ve CSS renk geçişleri
SVG ikonlar
Footer ve e-posta kayıt alanı tasarımı

Proje Hakkında:

Bu çalışma HTML ve CSS öğrenme amacıyla hazırlanmıştır. Görsel tasarım ve responsive yerleşim tamamlanmıştır.
Hamburger menünün açılıp kapanması, bağlantı yönlendirmeleri ve e-posta kayıt işlemi gibi işlevler henüz uygulanmamıştır.
